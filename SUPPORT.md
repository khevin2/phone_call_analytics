# Support

Thanks for using CallSense! This document outlines how to get help.

## Questions and troubleshooting

- Check the README for setup, permissions, and known limitations.
- Search existing issues to see if your question has already been answered.

## Bug reports

If you believe you found a bug, please open a new issue using the **Bug report** template.
Include steps to reproduce, device details, and any relevant logs.

## Feature requests

If you have an idea for a new feature, open a **Feature request** issue to discuss it.

## Security issues

Please follow the instructions in [SECURITY.md](SECURITY.md) for responsible disclosure.
